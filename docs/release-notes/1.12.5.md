### 1.12.5 {small}`2026-10-29`

#### Miscellaneous changes

- Deprecate {func}`~scanpy.tl.sim`, {func}`~scanpy.pl.sim`, {func}`~scanpy.datasets.toggleswitch`, {func}`~scanpy.pp.recipe_weinreb17`, {func}`~scanpy.queries.gene_coordinates`, and the undocumented `sc.datasets.burczynski06`, `sc.tl.paga_compare_paths`, `sc.tl.paga_degrees`, `sc.tl.paga_expression_entropies`, and `sc.pl.paga_adjacency`, which have next to no users.
  Remove unreachable code paths from {func}`~scanpy.tl.dpt` {smaller}`L Heumos` ({pr}`4390`)

#### Features

- Add {func}`scanpy.pp.normalize_shifted_clr` for PFlog shifted centered log-ratio normalization, a variance-stabilizing, depth-invariant and rank-preserving count transform {cite:p}`Booeshaghi2022`. By default, it estimates negative-binomial overdispersion and uses the Anscombe pseudocount. The complete centered result is stored in `X` or the selected layer. Because CLR centering generally maps zeros to non-zero values, the output is dense. {smaller}`R Baber` ({pr}`4160`)
- Add an ``ncols`` parameter to {func}`scanpy.pl.paga` so multi-color PAGA plots can be arranged in a configurable grid instead of a single row. {smaller}`A Moradniaei` ({pr}`4325`)
- Rename `mask_var`/`mask_obs` to `mask` in {func}`~scanpy.pp.pca`, {func}`~scanpy.pp.scale`, {func}`~scanpy.tl.rank_genes_groups`, and {func}`~scanpy.experimental.pp.normalize_pearson_residuals_pca`.
  The new parameter takes {mod}`anndata.acc` references, e.g. `A.var["highly_variable"]` {smaller}`P Angerer` ({pr}`4333`)

#### Bug fixes

- Fix {func}`~scanpy.pp.log1p` warning that `adata.X` is already log-transformed when transforming a layer or obsm {smaller}`M Arvind Khakharia` ({pr}`4298`)
- {func}`~scanpy.io.read_10x_mtx` no longer treats the gene symbol `nan` as missing. ({pr}`4329`)
- Fix {func}`~scanpy.pp.combat` with categorical `covariates`, which produced a singular design matrix and either raised or silently returned wrong values {smaller}`L Heumos` ({pr}`4389`)
- Support pynndescent 0.7 in {func}`~scanpy.pp.neighbors` and {func}`~scanpy.tl.ingest` {smaller}`E Roellin` ({pr}`4451`)
