Functions now say where they read from with `use` and where they write to with `out`, taking {mod}`anndata.acc` accessors (e.g. `A.layers["counts"]`) or {meth}`~anndata.acc.AdAcc.resolve`\ able strings (e.g. `"layers.counts"`).
A function’s `use` takes what was passed to the `out` of the function producing its input, e.g. `sc.pp.pca(adata, out=A.obsm["p"])` and then `sc.pp.neighbors(adata, use=A.obsm["p"])`:

Single input
: `use` is one accessor, deprecating `layer`, `obsm`, `use_rep` and `use_raw`,
  e.g. `sc.pp.log1p(adata, use=A.layers["counts"])`.

Outputs
: `out` is an accessor to write to (e.g. `sc.tl.umap(adata, out=A.obsm["umap2"])`),
  `out=True` to return the result instead (replacing `inplace=False`, `score_name` and `copy`),
  or `out=False` (the default) to write it to its default place,
  which is the input itself for functions transforming a matrix, e.g. {func}`~scanpy.pp.log1p`.
  This deprecates `key_added`.

Several outputs
: An accessor names the primary output `k`, e.g. `sc.pp.pca(adata, out=A.obsm["p"])`,
  and the others follow it: they are named `k` in kinds of places no other output goes to
  (`.varm["p"]` and `.uns["p"]`),
  and `k_{name}` otherwise (e.g. `sc.pp.neighbors(adata, out=A.obsp["nn"])` writes `.obsp["nn"]` and `.obsp["nn_distances"]`).
  A mapping of output names to accessors writes only the outputs it names,
  e.g. `out={"connectivities": A.obsp["conns"]}`,
  and `out=True` returns them as a {class}`~typing.NamedTuple` (e.g. {class}`~scanpy.pp.PcaOut`).
  {func}`~scanpy.pp.scrublet`, {func}`~scanpy.tl.score_genes_cell_cycle` and {func}`~scanpy.tl.dpt` only take a mapping,
  as none of their outputs is the primary one.

Neighborhood graphs
: Functions using {func}`~scanpy.pp.neighbors`’ results take the graph as `use`, e.g. `sc.tl.umap(adata, use=A.obsp["nn"])`,
  deprecating `neighbors_key`, `obsp` and `adjacency`.
  Distances and parameters are found where {func}`~scanpy.pp.neighbors` stored them alongside the graph, if they exist.
  {func}`~scanpy.tl.umap` lays out a graph with more than `2 * n_components` connected components using data:
  by default the representation {func}`~scanpy.pp.neighbors` used, otherwise pass e.g. `use={"graph": A.obsp["g"], "rep": A.obsm["pca"]}`.

Several inputs
: `use` is a mapping of input names to accessors,
  e.g. `use={"graph": A.obsp["conns"], "vals": A.obsm["X_pca"]}` for {func}`~scanpy.metrics.gearys_c` and {func}`~scanpy.metrics.morans_i`,
  deprecating their `use_graph`, `neighbors_key` and passing `vals` with an {class}`~anndata.AnnData`.

Groupings and covariates
: take references like `A.obs["batch"]`:
  `batch` replaces `batch_key` in {func}`~scanpy.pp.highly_variable_genes`, {func}`~scanpy.pp.scrublet` and the experimental Pearson residual functions,
  {func}`~scanpy.pp.combat`’s `key` and {func}`~scanpy.pp.regress_out`’s `keys` are renamed to `batch` and `covariates`,
  {func}`~scanpy.pp.harmony_integrate` takes `batch`,
  and `groupby` of {func}`~scanpy.tl.rank_genes_groups`, {func}`~scanpy.tl.filter_rank_genes_groups`, {func}`~scanpy.tl.dendrogram` and {func}`~scanpy.tl.embedding_density`
  as well as {func}`~scanpy.tl.paga`’s `groups` accept them.

Outputs only in `.uns`
: {func}`~scanpy.tl.rank_genes_groups`, {func}`~scanpy.tl.filter_rank_genes_groups`, {func}`~scanpy.tl.dendrogram` and {func}`~scanpy.tl.paga`
  take `out=True` to return their results.
  Until there are `.uns` accessors ({issue}`scverse/anndata#2657`),
  they keep `key_added` and the functions reading their results keep `key`.

Strings passed instead of accessors are {meth}`~anndata.acc.AdAcc.resolve`\ d (e.g. `"obs.batch"`),
except where a parameter already took strings with another meaning (e.g. column or `.obsm` key names):
there they keep it, unless {attr}`scanpy.settings.preset` is {attr}`~scanpy.Preset.ScanpyV2Preview`.

`copy` and `inplace` are deprecated everywhere: copy the {class}`~anndata.AnnData` yourself before calling a function, or pass `out=True`.
Only the subsetting functions {func}`~scanpy.pp.filter_cells`, {func}`~scanpy.pp.filter_genes` and {func}`~scanpy.pp.sample` keep `copy`, since copying the whole object first would be wasteful.
{func}`~scanpy.pp.calculate_qc_metrics` returns its metrics by default, but writes them with {attr}`~scanpy.Preset.ScanpyV2Preview`.
Since {attr}`~anndata.AnnData.raw` is on its way out, `use_raw` is deprecated: keep the data in a layer instead.
{func}`~scanpy.tl.embedding_density`’s `basis` is renamed to `use`, and {func}`~scanpy.get.obs_df` and {func}`~scanpy.get.var_df` take `use` instead of `layer`.
