Add a `use` parameter taking {mod}`anndata.acc` accessors (e.g. `A.layers["counts"]`) to the functions selecting an input matrix, deprecating their `layer`, `obsm` and `use_rep` parameters.

Functions writing results gain an `out` parameter saying where to write them, deprecating `key_added`:
pass an accessor (e.g. `out=A.obsm["umap"]`) to write a single output there,
a mapping (e.g. `out={"connectivities": A.obsp["conns"]}`) to only write the named outputs of functions with several,
a {class}`scanpy.Prefix` to prefix each output’s default name (e.g. `sc.pp.pca(adata, out=sc.Prefix("x"))` writes `.obsm["x_pca"]`),
or `out=True` to get the result returned instead (replacing `inplace=False` and `score_name`).
These functions also deprecate `copy`: copy the {class}`~anndata.AnnData` yourself before calling them.
Only the subsetting functions {func}`~scanpy.pp.filter_cells`, {func}`~scanpy.pp.filter_genes` and {func}`~scanpy.pp.sample` keep `copy`, since copying the whole object first would be wasteful.
{func}`~scanpy.pp.calculate_qc_metrics` returns its metrics by default, but writes them with {attr}`~scanpy.Preset.ScanpyV2Preview`.
{func}`~scanpy.metrics.gearys_c` and {func}`~scanpy.metrics.morans_i` take `use={"graph": …, "vals": …}`, deprecating `use_graph`, `neighbors_key` and passing `vals` with an {class}`~anndata.AnnData`.

Since {attr}`~anndata.AnnData.raw` is on its way out, `use_raw` is deprecated in {func}`~scanpy.pp.calculate_qc_metrics`, {func}`~scanpy.tl.score_genes`, {func}`~scanpy.tl.dendrogram`, {func}`~scanpy.tl.rank_genes_groups`, {func}`~scanpy.tl.filter_rank_genes_groups`, {func}`~scanpy.metrics.gearys_c` and {func}`~scanpy.metrics.morans_i`: keep the data in a layer instead {smaller}`P Angerer`
