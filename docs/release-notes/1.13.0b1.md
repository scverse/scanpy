### 1.13.0b1 {small}`2026-11-05`

#### Miscellaneous changes

- Deprecate {func}`~scanpy.tl.sim`, {func}`~scanpy.pl.sim`, {func}`~scanpy.datasets.toggleswitch`, {func}`~scanpy.pp.recipe_weinreb17`, {func}`~scanpy.queries.gene_coordinates`, and the undocumented `sc.datasets.burczynski06`, `sc.tl.paga_compare_paths`, `sc.tl.paga_degrees`, `sc.tl.paga_expression_entropies`, and `sc.pl.paga_adjacency`, which have next to no users.
  Remove unreachable code paths from {func}`~scanpy.tl.dpt` {smaller}`L Heumos` ({pr}`4390`)

#### Documentation

- Group the docs sidebar into Getting started, Guides, Reference and Project like the other scverse core packages, with new quickstart and citation pages {smaller}`L Heumos` ({pr}`4464`)

#### Features

- Add {func}`scanpy.pp.normalize_shifted_clr` for PFlog shifted centered log-ratio normalization, a variance-stabilizing, depth-invariant and rank-preserving count transform {cite:p}`Booeshaghi2022`. By default, it estimates negative-binomial overdispersion and uses the Anscombe pseudocount. The complete centered result is stored in `X` or the selected layer. Because CLR centering generally maps zeros to non-zero values, the output is dense. {smaller}`R Baber` ({pr}`4160`)
- Add an `ncols` parameter to {func}`scanpy.pl.paga` so multi-color PAGA plots can be arranged in a configurable grid instead of a single row. {smaller}`A Moradniaei` ({pr}`4325`)
- Rename `mask_var`/`mask_obs` to `mask` in {func}`~scanpy.pp.pca`, {func}`~scanpy.pp.scale`, {func}`~scanpy.tl.rank_genes_groups`, and {func}`~scanpy.experimental.pp.normalize_pearson_residuals_pca`.
  The new parameter takes {mod}`anndata.acc` references, e.g. `A.var["highly_variable"]` {smaller}`P Angerer` ({pr}`4333`)
- Functions now say where they read from with `use` and where they write to with `out`, taking {mod}`anndata.acc` accessors (e.g. `A.layers["counts"]`) or {meth}`~anndata.acc.AdAcc.resolve`\ able strings (e.g. `"layers.counts"`).
  A function’s `use` takes what was passed to the `out` of the function producing its input, e.g. `sc.pp.pca(adata, out=A.obsm["p"])` and then `sc.pp.neighbors(adata, use=A.obsm["p"])`:

  ```{container}
  Single input
  : `use` is one accessor, deprecating `layer`, `obsm`, `use_rep` and `use_raw`,
    e.g. `sc.pp.log1p(adata, use=A.layers["counts"])`.

  Outputs
  : `out` is an accessor to write to (e.g. `sc.tl.umap(adata, out=A.obsm["umap2"])`),
    `out=True` to return the result instead (replacing `inplace=False`, `score_name` and `copy`),
    or `out=False` (the default) to write it to its default place,
    which is the input itself for functions transforming a matrix, e.g. {func}`~scanpy.pp.log1p`.
    This deprecates `key_added`.
    {func}`~scanpy.pp.highly_variable_genes` only takes `out=True` or `out=False` until there are references to columns of DataFrames in {attr}`~anndata.AnnData.varm` ({issue}`scverse/anndata#2722`).

  Several outputs
  : An accessor names the primary output `k`, e.g. `sc.pp.pca(adata, out=A.obsm["p"])`,
    and the others follow it: they are named `k` in kinds of places no other output goes to
    (`.varm["p"]` and `.uns["p"]`),
    and `k_{name}` otherwise (e.g. `sc.pp.neighbors(adata, out=A.obsp["nn"])` writes `.obsp["nn"]` and `.obsp["nn_distances"]`).
    This also applies to the primary output’s default place (e.g. `out=A.obsp["connectivities"]` writes `.obsp["connectivities_distances"]`), only `out=False` writes to the default places.
    If the primary output goes to `A.X`, the others go to their default places.
    A mapping of output names to accessors writes only the outputs it names,
    e.g. `out={"connectivities": A.obsp["conns"]}` (typed as e.g. {class}`~scanpy.pp.NeighborsOut`),
    and two outputs can’t go to the same place.
    `out=True` returns them as a {class}`~typing.NamedTuple` (e.g. {class}`~scanpy.pp.PcaResult`).
    For now, {func}`~scanpy.pp.scrublet`, {func}`~scanpy.tl.score_genes_cell_cycle` and {func}`~scanpy.tl.dpt` only take a mapping,
    as none of their outputs is the primary one.
    Once there are `.uns` accessors ({issue}`scverse/anndata#2657`), they will take `out=A.uns["k"]` and store the derived mapping of accessors in there.

  Neighborhood graphs
  : Functions using {func}`~scanpy.pp.neighbors`’ results take the graph as `use`, e.g. `sc.tl.umap(adata, use=A.obsp["nn"])`,
    deprecating `neighbors_key`, `obsp` and `adjacency`
    ({func}`~scanpy.tl.ingest` keeps `neighbors_key` until there are `.uns` accessors).
    Distances and parameters are found where {func}`~scanpy.pp.neighbors` stored them alongside the graph, if they exist.
    {func}`~scanpy.tl.umap` lays out a graph with more than `2 * n_components` connected components using data:
    by default the representation {func}`~scanpy.pp.neighbors` used, otherwise pass e.g. `rep=A.obsm["pca"]`.
    {func}`~scanpy.metrics.gearys_c` and {func}`~scanpy.metrics.morans_i` also take the graph as `use`, deprecating `use_graph`,
    and their `vals` takes an accessor (e.g. `vals=A.obsm["pca"]`), deprecating `layer`, `obsm` and `obsp`.

  Groupings and covariates
  : take references like `A.obs["batch"]`:
    `batch` replaces `batch_key` in {func}`~scanpy.pp.highly_variable_genes`, {func}`~scanpy.pp.scrublet` and the experimental Pearson residual functions,
    {func}`~scanpy.pp.combat`’s `key` and {func}`~scanpy.pp.regress_out`’s `keys` are renamed to `batch` and `covariates`,
    {func}`~scanpy.pp.harmony_integrate` takes `batch`,
    and `groupby` of {func}`~scanpy.tl.rank_genes_groups`, {func}`~scanpy.tl.filter_rank_genes_groups`, {func}`~scanpy.tl.dendrogram` and {func}`~scanpy.tl.embedding_density`
    as well as {func}`~scanpy.tl.paga`’s `groups` accept them.

  Outputs only in `.uns`
  : {func}`~scanpy.tl.rank_genes_groups`, {func}`~scanpy.tl.filter_rank_genes_groups`, {func}`~scanpy.tl.dendrogram` and {func}`~scanpy.tl.paga`
    take `out=True` to return their results.
    Until there are `.uns` accessors ({issue}`scverse/anndata#2657`),
    they keep `key_added` (where they had one) and the functions reading their results keep `key`.
  ```

  Strings passed instead of accessors are {meth}`~anndata.acc.AdAcc.resolve`\ d (e.g. `"obs.batch"`),
  except where a parameter already took strings with another meaning (e.g. column or `.obsm` key names):
  there they keep it, unless {attr}`scanpy.settings.preset` is {attr}`~scanpy.Preset.ScanpyV2Preview`.
  Deprecated parameters (e.g. `batch_key`) keep their meaning regardless of preset.

  `copy` and `inplace` are deprecated everywhere: copy the {class}`~anndata.AnnData` yourself before calling a function, or pass `out=True`.
  Only the subsetting functions {func}`~scanpy.pp.filter_cells`, {func}`~scanpy.pp.filter_genes` and {func}`~scanpy.pp.sample` keep `copy`, since copying the whole object first would be wasteful.
  {func}`~scanpy.pp.calculate_qc_metrics` returns its metrics by default, but writes them with {attr}`~scanpy.Preset.ScanpyV2Preview`.
  Since {attr}`~anndata.AnnData.raw` is on its way out, `use_raw` is deprecated: keep the data in a layer instead.
  {func}`~scanpy.tl.embedding_density`’s `basis` is renamed to `use`, and {func}`~scanpy.get.obs_df` and {func}`~scanpy.get.var_df` take `use` instead of `layer`.

  {func}`~scanpy.tl.dpt` now works with diffusion maps written under a key, e.g. with {attr}`~scanpy.Preset.ScanpyV2Preview`,
  and batched {func}`~scanpy.pp.scrublet` now only writes its outputs instead of replacing all of {attr}`~anndata.AnnData.obs` {smaller}`P Angerer` ({pr}`4359`)

#### Bug fixes

- Fix {func}`~scanpy.pp.combat` with categorical `covariates`, which produced a singular design matrix and either raised or silently returned wrong values {smaller}`L Heumos` ({pr}`4389`)
- Fix `sc.pp.downsample_counts(total_counts=...)` silently doing nothing for dense `X` that is not C-contiguous, e.g. Fortran-ordered arrays. ({pr}`4408`)
- Fix {func}`~scanpy.pp.downsample_counts` assigning reads to the wrong entries for float32 data with more than 2**24 total counts {smaller}`P Paladugu` ({pr}`4414`)
- Fix {func}`~scanpy.tl.embedding_density` raising for `groupby` categories with fewer than 3 cells or degenerate coordinates; their density is now `NaN` and a warning is shown {smaller}`A Asok` ({pr}`4431`)
